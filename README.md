# AI-bolat v4.0.0 — ойын-сабақтар платформасы

Кіру: http://localhost:8790 (Wi-Fi-дағы оқушылар: http://<компьютер-IP>:8790)

## Іске қосу (Windows)
`start-windows.bat` екі рет басыңыз (немесе `npm start`). Деректер: `data/aibolat.db`.

## Демо
- Мұғалім: +7 700 000 00 01 / demo1234
- Оқушылар: +7 700 000 00 02…05 / demo1234; сынып «7 «А»» коды AIBLT7

## Нақты SMS қосу
`.env` файлына қосыңыз да, серверді қайта іске қосыңыз:
```
SMS_PROVIDER=mobizon
MOBIZON_API_KEY=сіздің_кілт
```
(SMSC.kz және Twilio да қолдау табады — `.env.example` қараңыз.) SMS_PROVIDER бос болса — DEV режимі: код экранда және сервер терезесінде көрсетіледі.

## AI
`.env`: AI_API_KEY, AI_BASE_URL, AI_MODEL (Gemini). Сабақтар алғаш ашылғанда AI жасайды және базаға сақталады; AI қолжетімсіз болса — офлайн үлгі сабақ.

## Тест (әзірлеушіге)
`node tests/mock-ai.js` + `AI_BASE_URL=http://127.0.0.1:8799 PORT=8795 npm start`, содан соң `node tests/e2e.js` (playwright-core қажет).

## Интернетке шығару (production) — v3.1
Толық қазақша нұсқаулық: `../ai-bolat-publish/НҰСҚАУЛЫҚ.md`. Қысқаша:
- **VPS (ұсынылады, ҚР-да, мыс. PS.kz):** `sudo bash deploy/vps/install.sh` → Docker + Caddy (HTTPS) + `.env`.

- Барлық баптаулар: `.env.example` (`NODE_ENV=production`, `PUBLIC_URL`, `AI_*`, `SMS_PROVIDER`, `APP_SECRET`, `ADMIN_SETUP_TOKEN`, `DEMO_*`, `ANDROID_CERT_SHA256` …).

- Тест: `node tests/prod-check.js` (өндіріс режимі), `tests/e2e*.js` (браузер).

## v4.0.0 — өзгерістер тізімі (changelog)
**Дизайн және қолжетімділік**
- Жаңа «Аспан мен Алтын» дизайн жүйесі (`public/css/v4.css`): таза қою/жарық тақырыптар, бет ауысу анимациялары, мобильді-бірінші түзетулер (390 px), `prefers-reduced-motion`, `forced-colors`.
- Пернетақта: «Негізгі мазмұнға өту» сілтемесі, `Esc` терезені жабады, `/` іздеуге өтеді, барлық иконка-батырмаларда `aria-label`, анық фокус сақинасы.

**Оқушы дашборды** (`#/` және жаңа `#/stats` «Прогресс»)
- 12 апталық белсенділік картасы, пәндер бойынша меңгеру, соңғы нәтижелер графигі, қайталау керек тақырыптар, сыныптағы орын, күнделікті XP мақсатын өзгерту.
- «Менің дедлайндарым»: мерзімі өткен / жақын / кешігіп тапсырылған тапсырмалар.

**Сабақтар**
- Видео/медиа слоттары: мұғалім YouTube, Vimeo, Google Slides, PhET сілтемесін қосады (тек ақ тізім, YouTube → youtube-nocookie, басқанда ғана жүктеледі).
- «⚡ Жылдам тексеру»: сабақ соңында 3 сұрақ, бірден түсіндірмесімен.

**AI көмекші Болат**
- Көмек деңгейлері: 💡 Ишара → 📐 Ереже → 🪜 Қадам (жауапты бәрібір айтпайды). Ағынды (streaming) жауап сақталды.
- Дауыспен енгізу (Web Speech API, браузер қолдаса; kk-KZ / ru-RU / en-US).

**Мұғалім құралдары**
- Басты бетте «Сыныптар шолуы»: орындалуы, орташа %, назар аудару керек оқушылар, жақын дедлайндар.
- `#/report/<сынып>` — автотексеру есебі: әр тапсырма бойынша уақытында / кешікті / тапсырмады, баға таралуы, ең қиын сұрақтар; оқушылар кестесі; **CSV** экспорт және **PDF/басып шығару** беті.
- Тапсырма мерзімін, ұпайын, кешігуге рұқсатты өзгерту; хабарландыруды бекіту (📌) және өшіру.

**PWA және өнімділік**
- Service worker v4: бүкіл қабықша алдын ала кэштеледі; статика stale-while-revalidate; каталог, ашылған сабақтар және дашборд интернетсіз ашылады; шыққанда API кэші тазаланады; жаңа нұсқа туралы хабар.
- `vendor/` файлдарына 30 күндік кэш, жаңа индекстер (results, sessions).

**Қауіпсіздік**
- `/app/` үшін қатаң Content-Security-Policy (inline скриптсіз; iframe тек ақ тізімдегі хосттар), `frame-ancestors 'self'`.
- CSV формула-инъекциясынан қорғау, медиа URL тексеру, ескірген сессияларды тазалау, микрофон тек өз доменге.

**Деректер**
- Миграция деструктивті емес: тек `CREATE TABLE IF NOT EXISTS` / `ADD COLUMN` (`users.daily_goal`, `users.prefs`, `assignments.points|allow_late|max_attempts`, `announcements.pinned`, `lesson_media`, `schema_meta`). v3.2 базасы өзгеріссіз ашылады (`tests/migrate-v4.js`).

**Тесттер**: `tests/e2e-v4.js` (API + браузер + скриншоттар `screenshots/v4-*`), `tests/migrate-v4.js` (`V32_DIR=<v3.2 папкасы>`). Ескі тесттер `CHROME=<chrome жолы>` айнымалысын қолданады.
